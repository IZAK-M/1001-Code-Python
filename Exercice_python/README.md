# Exercice_python

Ce dossier regroupe des exercices Python pratiques, organisés par notebook, réalisés dans le cadre de mon apprentissage personnel.

## 📁 Organisation

Les exercices sont répartis dans plusieurs notebooks selon leur niveau de difficulté :

- **`facile.ipynb`** — Exercices de bases (variables, boucles, conditions, fonctions simples...)
- **`intermediaire.ipynb`** — Exercices un peu plus poussés (structures de données, algorithmes simples...)
- **`avance.ipynb`** — Exercices plus complexes (algorithmique avancée, structures plus riches...)

Chaque notebook contient plusieurs exercices, chacun présenté avec :
1. L'énoncé de l'exercice
2. La solution codée et commentée
3. La source de l'exercice

## 📚 Sources

Les exercices proviennent de différents sites trouvés en ligne. La source est systématiquement indiquée au-dessus de chaque exercice.

| Source | Lien |
|---|---|

## 🎯 Objectif

Ce dossier me sert de support d'entraînement personnel pour progresser en Python, en pratiquant régulièrement des exercices de difficulté croissante.
